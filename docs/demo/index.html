The Solution

One command.
Done in seconds.

automation_central is a shared, version-controlled AI automation library that lives alongside your code. Type a slash command in VS Code — Claude or Copilot picks up the right agent, runs the right script, and delivers structured output directly to your workflow.

Every tool your team already uses — Azure DevOps, GitHub, Teams, Outlook — is wired in. No copy-pasting between tabs. No prompt engineering on the fly.

The catalog maintains itself
Any engineer can contribute a new skill in ~15 minutes. Standards are enforced automatically.
✓
/add-skill scaffolds everything
One command generates the skill definition, registers it in both Claude and Copilot catalogs, and links it to the right specialist agent. No manual wiring.
✓
Validators enforce quality before merge
validate_skill.py and validate_agent.py check naming conventions, required fields, and cross-references — blocking non-compliant entries before they hit main.
✓
Catalog auto-regenerates on every change
generate_catalog.py rebuilds the full skill and agent directory automatically. No docs to maintain by hand — it's always up to date.
✓
One definition, two tools
Skills added to automation_central are instantly available to both Claude Code and GitHub Copilot users. The whole team benefits from every contribution.
